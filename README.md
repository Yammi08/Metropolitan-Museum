# Metropolitan-Museum
Aplicación que consume la API pública del [Metropolitan Museum of Art](https://metmuseum.github.io/#search) para realizar búsquedas de obras de arte y mostrar detalles relevantes.
en esta aplicacion se usa ES Modules para buscar en la api por nombre
```
npm git clone git@github.com:Yammi08/Metropolitan-Museum.git
npm init
npm run dev
```
